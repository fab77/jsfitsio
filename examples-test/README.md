# jsfitsio manual examples

This directory contains small manual integration examples used to verify the
public jsfitsio API from Node.js and from a browser.

The FITS files used by some examples are intentionally not stored in the Git
repository. Real FITS datasets can be downloaded using the commands below,
while synthetic FITS files can be generated using the scripts in `../scripts`.

## Build jsfitsio

Before running the examples, build the library from the project root:

```bash
npm run build
```

The Node.js examples import the local ESM build from:

```text
../lib-esm/index.mjs
```

---

## Npix43348.fits

Used by:

- `read-local.mjs`
- `read-local-image.mjs`
- `read-typed-data.mjs`
- `write-local.mjs`

Download it from the ESA skies service:

```bash
cd examples-test

curl -L \
  -o Npix43348.fits \
  "https://skies.esac.esa.int/Herschel/normalized/PACS_hips160/Norder8/Dir40000/Npix43348.fits"
```

---

## ngc6503.fits

Used by:

- `read-cube.mjs`

This is a public FITS data cube used to test N-dimensional image support.

Download it with:

```bash
cd examples-test

curl -L \
  -o ngc6503.fits \
  "https://fits.gsfc.nasa.gov/nrao_data/samples/cubes/ngc6503.fits"
```

The file contains a FITS data cube with degenerate axes, so the example also
demonstrates how to inspect the complete FITS shape and its non-degenerate
dimensions.

## Synthetic FITS files

The remaining FITS files are generated locally and do not need to be
downloaded.

From the project root, generate them with:

```bash
npx tsx scripts/generate-multi-hdu.ts
npx tsx scripts/generate-bintable.ts
npx tsx scripts/generate-ascii-table.ts
npx tsx scripts/generate-cube.ts
```

These scripts generate the fixtures used by examples such as:

```text
multi-hdu.fits
bintable.fits
ascii-table.fits
```

## Running the Node.js examples

From the project root:

```bash
node examples-test/read-url.mjs
node examples-test/read-local.mjs
node examples-test/read-local-image.mjs
node examples-test/read-typed-data.mjs
node examples-test/read-cube.mjs
node examples-test/read-multi-hdu.mjs
node examples-test/read-bintable.mjs
node examples-test/read-ascii-table.mjs
node examples-test/write-local.mjs
```

## Browser example

Build the browser bundle first:

```bash
npm run build
```

Then start a local HTTP server from the project root:

```bash
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000/examples-test/browser-example.html
```

The browser example uses the bundle generated in:

```text
dist/jsfitsio.js
```

---

## Generated files

FITS files in this directory are local fixtures and are intentionally excluded
from Git.

They can be downloaded or regenerated using the instructions above.

In particular, `output.fits` is generated by `write-local.mjs` and should not
be committed.
